# Class 10 NCERT Mathematics

Source PDFs for the Class 10 problems. Class 10 has a single Mathematics textbook, so there is no part 1 / part 2 split as in `class8_NCERT_part1` and `class8_NCERT_part2`.

Each chapter has its own sub-folder. Problem IDs use NCERT's code for the Class 10 Maths chapter PDFs, `jemh1XX` (`XX` = chapter number); for example `g10-jemh110-ex-10-2-q6` is Chapter 10, Exercise 10.2, Question 6.
